# 학급 상담 관찰 기록장

선생님이 상담 기록을 **내 구글 스프레드시트**에 저장하는 웹앱입니다.
HTML 파일 하나와 Google Apps Script 코드로 이루어져 있으며, 별도의 서버나 유료 서비스, AI API를 쓰지 않습니다.

- **바로 쓰기**: https://tuiumssaem-edu.github.io/counseling-log/
- 처음 접속하면 안내에 따라 내 스프레드시트와 한 번만 연결하면 됩니다.

## 이런 점이 다릅니다

- **학생 이름은 실명으로 저장되지 않습니다.** 교사가 정한 비밀번호로 브라우저 안에서 암호화한 뒤 저장합니다. 시트에는 암호문만 남습니다.
- **학생별로 시트가 따로 만들어집니다.** 시트 이름도 `학생_S7K2M9`처럼 코드로 만들어지고, 모든 학생 시트의 제목 행은 같습니다.
- **시트와 제목 행은 자동으로 만들어집니다.** 빈 스프레드시트에서 시작하면 됩니다.
- **여러 기기에서 쓸 수 있습니다.** 같은 웹앱 주소와 같은 비밀번호를 넣으면 개인 노트북과 업무용 컴퓨터에서 같은 기록을 씁니다.
- **기록은 각자의 구글 드라이브에만 있습니다.** 이 앱을 쓰는 선생님마다 자기 스프레드시트와 비밀번호를 따로 만듭니다.

## 처음 설정 (한 번만)

1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다.
2. 스프레드시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 앱의 **⚙ 설정 → 시트 연결 안내 → 앱스크립트 코드 복사**를 누르고, `Code.gs` 내용을 모두 지운 뒤 붙여 넣고 저장합니다.
   (이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs)와 같은 코드입니다.)
4. **배포 → 새 배포 → 웹 앱**을 고르고 아래처럼 설정한 뒤 배포합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 권한 요청이 나오면 내 계정으로 허용합니다. ‘확인되지 않은 앱’ 경고는 직접 만든 스크립트라서 나오며, **고급 → (프로젝트 이름)(으)로 이동**을 누르면 됩니다.
5. 받은 **웹 앱 URL**(`/exec`로 끝남)을 앱의 웹앱 주소 칸에 넣고 **저장하고 연결 테스트**를 누릅니다.
6. **비밀번호를 정합니다.** 배포한 뒤 바로 정해 주세요. 처음 비밀번호를 정한 사람이 그 서버의 주인이 됩니다.

## 쓰는 방법

- **상담 기록**: 학생을 고르고 일시·대상·방법·시간·상담 내용·비고를 적은 뒤 **저장**을 누릅니다. 오른쪽에 그 학생의 기록이 최신순으로 보입니다.
- **⚙ 설정 → 학생 관리**: 학생 등록(이름만 필수), 수정, 숨기기, 완전 삭제
  - **숨기기**: 목록에서만 빠지고 시트와 기록은 보관됩니다. 다시 보이게 할 수 있습니다.
  - **완전 삭제**: 학생 시트까지 지웁니다. 되돌릴 수 없습니다.
- **🔒 잠그기**: 학생 이름이 보이지 않게 잠급니다.
- **이 기기에서 기억하기**: 혼자 쓰는 기기에서만 켜 주세요. 함께 쓰는 컴퓨터에서는 끄고 사용하세요.

## 시트 구조

| 시트 | 1행 제목 |
|---|---|
| `학생목록` | 학생ID, 시트이름, 이름(암호화), 학년, 반, 번호, 상태, 등록일시, 수정일시 |
| `학생_<학생ID>` (학생마다 하나) | 기록ID, 저장일시, 상담일시, 대상, 방법, 상담시간, 상담내용, 비고 |

시트 이름이나 제목 행을 바꾸지 마세요. 제목 행이 바뀌면 앱이 다음 저장 때 다시 맞춥니다.

## 보안과 개인정보

- 비밀번호에서 PBKDF2(SHA-256, 310,000회)로 두 가지 값을 만듭니다.
  - **이름 암호화 열쇠**: 학생 이름을 AES-GCM으로 암호화합니다. 서버로 보내지 않습니다.
  - **접속 확인 값**: 서버에는 이 값의 SHA-256 해시만 저장됩니다. 값이 맞지 않으면 기록을 읽거나 쓸 수 없습니다.
- 비밀번호가 10번 틀리면 10분 동안 잠깁니다.
- 웹앱을 ‘모든 사용자’로 배포하는 이유는 깃허브에 있는 이 앱이 웹앱에 접속할 수 있게 하기 위해서입니다. 비밀번호를 모르는 사람은 아무것도 읽거나 쓸 수 없습니다.
- **상담 내용과 비고는 암호화하지 않습니다.** 스프레드시트에서 바로 읽을 수 있도록 하기 위해서입니다. 상담 내용에 학생 실명을 적지 않도록 주의해 주세요.
- 스프레드시트는 필요한 사람에게만 공유하세요.

## 비밀번호를 잊었을 때

학생 이름을 되살릴 방법은 없습니다. 상담 내용은 시트에 그대로 남아 있습니다.
새로 시작하려면 새 스프레드시트로 처음 설정부터 다시 하세요.

## 코드를 고쳤을 때

- `apps-script/Code.gs`를 고쳤다면 Apps Script에 다시 붙여 넣고 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 눌러야 반영됩니다. 웹앱 주소는 바뀌지 않습니다.
- 앱 화면은 `src/index.template.html`에서 고친 뒤 `python3 tools/build.py`를 실행하면 `index.html`이 만들어집니다. (앱의 ‘코드 복사’ 버튼에 들어갈 `Code.gs`를 함께 넣어 줍니다.)

## 파일 구성

```
index.html                 실제로 여는 앱 (빌드 결과)
src/index.template.html    앱 화면 원본
apps-script/Code.gs        스프레드시트에 붙여 넣는 서버 코드
tools/build.py             index.html 만들기
```
